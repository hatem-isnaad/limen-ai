# Phase Workflow

## Start Phase

1. Read phase goals in docs/project/ROADMAP.md
2. Update docs/project/STATUS.md → phase in progress
3. Create checklist items for phase

## During Phase

1. Implement only phase scope
2. Write tests alongside code
3. Update docs with examples

## End Phase

1. Run `composer test`
2. Run architecture tests
3. Update docs/project/STATUS.md, CHANGELOG.md, docs/project/PROJECT_MANIFEST.md
4. Update docs/project/AI_SPEC.md checklist
5. List deferred items in docs/project/IMPLEMENTATION.md
6. Request review before next phase
