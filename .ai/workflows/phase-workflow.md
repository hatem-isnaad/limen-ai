# Phase Workflow

## Start Phase

1. Read phase goals in ROADMAP.md
2. Update STATUS.md → phase in progress
3. Create checklist items for phase

## During Phase

1. Implement only phase scope
2. Write tests alongside code
3. Update docs with examples

## End Phase

1. Run `composer test`
2. Run architecture tests
3. Update STATUS.md, CHANGELOG.md, PROJECT_MANIFEST.md
4. Update AI_SPEC.md checklist
5. List deferred items in IMPLEMENTATION.md
6. Request review before next phase
